## 三、主要学习收获

### 1. 字符串处理

学习使用 `strip()` 去除两端空格、`lower()` 统一大小写、`startswith()` 判断字符串开头，以及 `endswith()` 判断文件扩展名。

### 2. 条件判断

通过 `if`、`elif` 和 `else`，根据不同的输入执行不同的代码分支。条件的顺序会影响程序结果，因此需要先判断更具体的情况。

### 3. 数值转换与计算

在 Math Interpreter 中，使用 `split()` 拆分数学表达式，使用 `float()` 将字符串转换成数字，再根据运算符执行计算。

在 Meal Time 中，学习将小时和分钟转换成小数小时。例如，12:30 可以转换为 12.5。

### 4. 函数与程序结构

通过 Meal Time 练习定义函数、传递参数和使用 `return` 返回计算结果，初步理解将程序拆分为多个功能部分的意义。

### 5. Git 版本管理

练习使用 `git add` 暂存文件、使用 `git commit` 保存代码版本，以及使用 `git status` 检查工作区状态。

## 四、遇到的问题与解决方法

### 问题一：Git 添加文件时路径错误

在已经进入 `pset1` 目录的情况下，仍使用了 `CS50P/pset1/deep.py` 路径，导致 Git 无法找到文件。

解决方法：使用当前目录下的相对路径，例如 `git add deep.py`。

### 问题二：Math Interpreter 输入格式错误

输入 `8/6` 时，程序无法通过 `split()` 拆分成三个部分。

解决方法：按照程序预期输入 `8 / 6`。之后程序正确输出 `1.3333333333333333`。

### 问题三：Meal Time 使用了全角冒号

输入 `12：30` 时，程序无法识别英文半角冒号 `:`。

解决方法：切换到英文输入法，输入 `12:30`，程序随后正确输出 `lunch time`。
