\# LearnCpp 调试练习记录



\## 一、学习内容



学习 LearnCpp 3.1–3.5，练习调试流程、常见错误识别与修复，以及 GDB 基本操作。



\## 二、实验一：数组越界



\*\*错误代码：\*\*



```cpp

int numbers\[3]{10, 20, 30};

std::cout << numbers\[3] << '\\n';

```



\*\*问题分析：\*\*



数组长度为 3，有效下标是 0、1、2。访问 `numbers\[3]` 超出了数组范围，导致未定义行为。



\*\*修复方法：\*\*



```cpp

std::cout << numbers\[2] << '\\n';

```



\*\*验证结果：\*\* 程序输出 `30`。



\## 三、实验二：未初始化变量



\*\*错误代码：\*\*



```cpp

int score;

std::cout << score << '\\n';

```



\*\*问题分析：\*\*



局部变量 `score` 没有初始化就被读取。编译器通过 `-Wuninitialized` 给出了警告。



\*\*修复方法：\*\*



```cpp

int score{0};

```



\*\*验证结果：\*\* 编译警告消失，程序输出 `0`。



注意：错误版本偶然输出 `0`，不代表读取未初始化变量是安全的。



\## 四、实验三：逻辑错误



\*\*错误代码：\*\*



```cpp

int average{a + b / 2};

```



当 `a = 10`、`b = 20` 时，由于除法优先于加法，计算结果为 20，而不是预期的 15。



\*\*修复方法：\*\*



```cpp

int average{(a + b) / 2};

```



\*\*验证结果：\*\* `average` 的值为 `15`。



\## 五、GDB 调试操作



本次使用的命令：



| 命令 | 用途 |

|---|---|

| `break main` | 在 main 函数入口设置断点 |

| `run` | 启动程序 |

| `next` | 单步执行 |

| `list` | 查看附近的源代码 |

| `print a` | 查看变量 a 的值 |

| `print b` | 查看变量 b 的值 |

| `print average` | 查看平均值变量 |

| `continue` | 继续运行 |

| `quit` | 退出 GDB |



通过 GDB 验证了变量初始化、逐行执行和计算结果。



\## 六、学习总结



本次练习让我理解了三种常见错误的区别：



1\. 数组越界：访问了无效的数组下标。

2\. 未初始化变量：变量没有获得明确的初始值就被读取。

3\. 逻辑错误：程序可以正常编译和运行，但计算结果不符合预期。



以后调试程序时，我会先检查编译器警告，再通过小规模测试观察结果，必要时使用断点、单步执行和变量检查定位问题，最后重新编译并验证修复效果。
