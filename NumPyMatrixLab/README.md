\### 三、核心知识



矩阵尺寸表示为 (行数, 列数)。



矩阵乘法要求：

左矩阵列数 = 右矩阵行数。



若 A 是 m×n，B 是 n×p，

则 A @ B 的结果为 m×p。



NumPy 运算：



\- A.shape：查看尺寸

\- A @ B：矩阵乘法

\- A \* B：逐元素乘法



\### 四、实验结果



实验1：创建矩阵，检查尺寸。



实验2：

\[\[19, 22],

实验3：

实验4：

A @ B 与 B @ A 不相等。



实验5：

(2, 3) @ (3, 2) -> (2, 2)



实验6：

(100, 30) @ (30, 2) -> (100, 2)

3\. @ 和 \* 是不同的运算。

4\. 使用随机种子可以重复实验。

5\. 矩阵是表示优化种群的重要数据结构。
